# Étiquettes de triage

Les skills parlent de cinq rôles de triage canoniques. Ce fichier les relie aux valeurs utilisées ici. Avec le suivi en Markdown local, la valeur s'écrit dans la ligne `Status:` du fichier d'issue.

| Étiquette mattpocock/skills | Valeur dans ce dépôt | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | À évaluer par Quentin |
| `needs-info` | `needs-info` | En attente d'informations |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifié, prêt pour un agent autonome |
| `ready-for-human` | `ready-for-human` | Demande une implémentation humaine |
| `wontfix` | `wontfix` | Ne sera pas traité |

Quand un skill mentionne un rôle (par exemple « appliquer l'étiquette prête pour un agent »), utiliser la valeur correspondante de ce tableau.

Modifier la colonne de droite pour l'adapter au vocabulaire réellement utilisé.
